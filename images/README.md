# Videos del hero

## Cómo agregar un video:

1. Descargá un video de: https://www.pexels.com/search/videos/villa%20gesell/
2. Guardalo como: `villa-gesell.mp4`
3. Avísame para integrarlo en el código

## Formato recomendado:
- MP4 (H.264)
- Resolución: 1920x1080 (Full HD) o 1280x720 (HD)
- Duración: 10-30 segundos (se repite en loop)
- Sin necesidad de audio (va a estar muted)

## Tamaño máximo sugerido:
- Menos de 10MB para carga rápida
- Vercel tiene límite de 50MB por archivo
